# 基于 SincNet 的听觉信号分类

本项目整理自 2024 年 6–9 月在 **UC Irvine Hearing Lab** 开展的研究工作，使用现有 SincNet 架构对原始声音波形进行二分类，并比较不同第一层滤波器数量下的表现。

[English README and setup instructions](README.md)

## 当时做了什么

前期尚未获得受试者实验数据，因此先用 Python 生成模拟音频，搭建训练和评估流程。后期获得实验数据后，依据保存的声学参数重建声音，在实验音频上重新训练和测试。

| 数据 | 来源 | 总量 | 训练 / 测试 |
|---|---|---:|---:|
| 模拟音频 | 自行设定的频率、幅度扰动和相位规则 | 300 | 240 / 60 |
| 实验音频 | 受试者听觉实验保存的频率、声级、相位参数 | 400 | 320 / 80 |

两套数据分别训练、分别测试，并未验证“模拟数据训练、实验数据直接测试”的迁移效果。

模型预测的是**刺激类别**。实验音频标签来自原始重建流程中的 `nint` 分类，不是受试者实际回答 `resp`。因此，该项目尚未验证人类回答预测、减少真人测试次数或估计个体听觉滤波特征。

模拟音频中，两类声音都包含目标频率，区别是目标成分的平均幅度：目标频率为 500、1000、1500、2000、2500 Hz，对应幅度系数均值为 53 与 50，并叠加随机扰动。这些系数不是校准后的声压级。

## 保存的实验结果

下表由历史日志中的整段音频错误率 `err_te_snt` 换算，整理期间没有重新训练。

| 数据 | 第一层滤波器数 | 最后一次评估准确率 | 日志中最高准确率 |
|---|---:|---:|---:|
| 模拟 | 5 | 46.67% | 53.33% |
| 模拟 | 10 | 41.67% | 51.67% |
| 模拟 | 80 | 50.00% | 60.00% |
| 实验 | 5 | 67.50% | 75.00% |
| 实验 | 10 | **76.25%** | **78.75%** |
| 实验 | 15 | 73.75% | 77.50% |
| 实验 | 20 | 73.75% | 77.50% |

实验音频记录中，增加滤波器数量没有持续改善最后一次测试表现。模拟数据则出现训练误差很低、测试表现仍然较弱的现象。

这些结果来自较小的固定划分，同一测试集在训练期间被反复评估，最高成绩不是独立最终测试结果。部分日志包含重复的 epoch 0，未将它们当作独立重复实验。旧评估代码的帧计数边界问题及绘图限制详见 [方法与局限](docs/METHODOLOGY.md)。

## 如何查看和运行

- 直接查看 [结果汇总 CSV](results/summary.csv) 和 [原始日志](results/raw)。
- 运行 [结果分析 notebook](analysis/results_analysis.ipynb)，核对汇总并生成学习曲线；不需要受试者数据或 GPU。
- 数据生成入口为 `simulation_WAV.ipynb`、`experiment_WAV.ipynb`；文件列表与标签入口为 `generate_scp.ipynb`。
- 训练入口为 `sincnet_binary_response.py`，配置位于 `cfg/`。训练依赖 NVIDIA GPU 和可用的 CUDA 版 PyTorch；完整步骤见英文 README。

原始环境版本没有保存，`requirements.txt` 是依赖清单，不是已验证的版本锁定文件。本次整理环境中没有可运行的 Python，因此 notebook 和训练没有执行验证。

模拟生成在本次整理中新增了固定随机种子，新的波形不会与历史未设种子的波形完全一致。已保存的数据划分保留不变；生成程序不会覆盖已有音频。
